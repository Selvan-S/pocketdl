# PocketDL v0.1.3

## Focus
Analysis before download and visible browser request context options.

## New
- `POST /api/analyze` runs yt-dlp with `--skip-download --dump-single-json` and returns metadata plus a normalized format list.
- Analyze retries once with Chrome impersonation when Auto mode sees an HTTP 403.
- Download UI now exposes optional page URL, Referer, Origin, User-Agent, and impersonation mode.
- Analysis can prefill the filename from the extracted media title.
- Format inspection is informational in this release; exact format selection remains a later feature.

## Notes
Sensitive `Cookie` and `Authorization` headers remain rejected. Browser capture/cookie integration is intentionally deferred to a later release.
