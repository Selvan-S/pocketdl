# PocketDL 0.2.2

## Capture hygiene

Browser capture now prioritizes HLS/DASH manifests and skips obvious segment requests such as `.m4s`, `.ts`, and common chunk/fragment URL patterns.

## Metadata

Captured sources expose best-effort duration, size, width, and height. The browser supplies Content-Length when available; the backend asynchronously enriches captures with ffprobe using the captured request context.

## UX

Capture cards are collapsed by default. The Browser Capture and Download Queue sections can also be collapsed. The extension popup shows duration/size and uses collapsible capture rows.
