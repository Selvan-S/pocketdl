# Changelog

## 0.2.1

- Added persistent download-directory settings controlled from the web UI.
- Added open-folder and reset-default actions.
- Improved browser capture UI and popup quick-download action.
- Added normalized capture deduplication for expiring/signed media URLs.
- Added content-type based capture for common direct video/audio resources.
- Updated extension to expose refreshed capture context while continuing to exclude credential headers.
- Added tests for settings persistence and capture refresh/deduplication.
